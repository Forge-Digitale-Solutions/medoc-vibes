# Médoc data

## `medoc-communes-codes-postaux.csv`

Allowlist of **56 communes** covering the Médoc triangle Lacanau → Pointe du Verdon → Blanquefort, with **16 postal codes**.

**Filter by commune name, not postal code alone.** Codes `33160`, `33290`, `33320`, and `33680` slightly overflow the strict Médoc perimeter (they also cover neighbouring non-Médoc localities).
