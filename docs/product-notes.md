# Notes produit — Médoc Vibes

## Attribution partenaires (sans budget tracking lourd)

Proxies réalistes (du plus simple au plus fort) :

1. **Clics trackés** : “Itinéraire”, “Appeler”, “Site”, “Réserver” (UTM / deep link) — pas une preuve de passage, mais vendable en stats.
2. **Offre “montre l’écran”** : avantage partenaire (apéro offert, -10 %) débloqué dans l’app → le staff voit le stamp / QR une fois. Fragile mais compris des commerçants.
3. **Code unique court** (par user×lieu×jour) dit au comptoir — même idée, un peu plus pro.
4. **Check-in volontaire** (“J’y suis”) géofencé — opt-in, jamais fiable à 100 %.

À ne pas promettre au MVP : attribution offline parfaite type affiliation carte bancaire.

## Compléments Médoc utiles (au-delà du dit)

Priorité : **ce qui fait vivre la région** (pas un annuaire générique) — tourisme / loisir ancré Médoc.

- **Agenda “ce soir / ce week-end”** (plus différenciant qu’un annuaire)
- **Vides-greniers**, marchés, guinguettes, fêtes de village, concerts plage
- Data vides-greniers / vie locale spontanée : **partielle** (OpenAgenda / DATAtourisme si OT) → combler via partenaires + curation
- Spots surf / écoles + conditions (si source dispo) ; zones pêche réglementées (prudence légale)
- Voies cyclables / locations vélo ; navettes saisonnières
- Plages (baignade, chiens, accessibilité) — en lien/complément PNR plutôt qu’en concurrence
- Châteaux : portes ouvertes, dégustations, events (pas le catalogue vin complet)
- Hébergements légers (campings, aires) si data.gouv/OT le permet
- **Bornes IRVE** (déjà évoqué) + parkings covoit si utile
- Multilingue FR/EN pour touristes
- Mode hors-ligne minimal (carte des favoris) — réseau faible en Médoc
- Widget / notif locale “ce week-end près de toi” (après MVP)
